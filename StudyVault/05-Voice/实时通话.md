# 实时通话

重要度：★★★。阅读基线见 [[源码地图]]，先尝试 [[实时通话练习]] 再展开答案。

## Purpose · 职责

WebRTC 承载音频和数据通道；Pipecat 在对话引擎外包装 STT 与 Fish TTS。Calls 对 API 隐藏连接细节，TurnTaking 决定说话轮转，CallOutcome 负责通话结果和限额。

## Key Files · 关键源码

| 源文件（项目根目录相对路径） | 职责 |
|---|---|
| `backend/src/eidolon/call.py` | Calls 信令边界、Speech 端口、CallTurns 管线 |
| `backend/src/eidolon/turn_taking.py` | 插话、续说和打断决策 |
| `backend/src/eidolon/call_outcome.py` | 连接、结束原因、消费与时长结算 |
| `backend/src/eidolon/bailian.py` | 百炼语音识别 |
| `frontend/src/lib/call.ts` | Pipecat 客户端与 SmallWebRTCTransport |
| `frontend/src/lib/microphone.ts` | 麦克风获取和切换 |

## Public Interface · 对外边界

| 入口 | 用途 |
|---|---|
| `GET /api/ice-servers` | 检查可用性、返回 ICE/临时 TURN 凭据与通话设置 |
| `POST /api/offer` | SDP 建连或已有 pc_id 重协商 |
| `PATCH /api/offer` | trickle ICE 候选 |
| `CallTurns` | 最终识别/通话内 user-text → 引擎 → TTS 与字幕 |
| `startCall` / `Call` | 前端连接、静音、文字发送、切麦与挂断 |

## Internal Flow · 内部流程

```text
microphone -> WebRTC input -> STT -> CallTurns -> ConversationEngine
                                              |               |
                                  TurnTaking / Outcome    Japanese segments
                                              |               v
+---------- browser <----- WebRTC audio output <----- Fish TTS
| subtitles + done + emotion + ended <----- data channel
+---------- LiveConversation -> CallLayer / Stand
```

## Configuration · 配置

| 配置 | 含义 |
|---|---|
| `STT_PROVIDER` | soniox（默认）或 bailian |
| `SONIOX_API_KEY` / `DASHSCOPE_API_KEY` | 对应识别服务 |
| `FISH_AUDIO_API_KEY/MODEL` | 合成与模型 |
| `EIDOLON_ICE_SERVERS` / `EIDOLON_TURN_URLS/SECRET` | ICE 与临时中继凭据 |
| `EIDOLON_CALL_MINUTES/TURNS_PER_CALL/CONCURRENT_CALLS` | 时长、回合、并发边界 |

## Testing · 如何验证

在 `backend/`：`uv run pytest tests/test_voice_call.py tests/test_voice_interruption.py tests/test_call_outcome.py tests/test_turn_taking.py`。在 `frontend/`：`npm test -- src/lib/call.test.ts src/lib/microphone.test.ts`。浏览器验收还需构建版和假麦克风，见 [[部署与开发验证]]。

> [!warning] 边界与常见误读
> 信令成功不是实际已接通；计时从 connected 开始。通话中打字也走 CallTurns，不另发普通文字回合。麦克风静音和只看文字是不同控制。拦 /api/offer 只能制造拨号阶段拒绝，不能模拟连接后的 ended。
