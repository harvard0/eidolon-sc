# 模型协议与自带密钥

重要度：★★★。阅读基线见 [[源码地图]]，先尝试 [[模型协议与自带密钥练习]] 再展开答案。

## Purpose · 职责

协议适配层把模型流统一成文本、工具调用与推理载荷。密钥选择在回合/通话开始时固定；部署客户端可热替换，但进行中的调用持有旧租约，用户自带密钥失败则显式失败。

## Key Files · 关键源码

| 源文件（项目根目录相对路径） | 职责 |
|---|---|
| `backend/src/eidolon/llm/__init__.py` | ChatMessage、ChatLLM、ToolCall、Reasoning 等统一类型 |
| `backend/src/eidolon/llm/providers.py` | 按协议创建适配器 |
| `backend/src/eidolon/llm/openai_compat.py` | Chat Completions |
| `backend/src/eidolon/llm/responses.py` | Responses |
| `backend/src/eidolon/llm/anthropic.py` | Anthropic Messages |
| `backend/src/eidolon/own_keys.py` | 临时服务选择、校验、错误掩码与公网地址限制 |
| `backend/src/eidolon/service_clients.py` | Swappable 与 Lease |
| `frontend/src/lib/localOwnKeys.ts` | 按用户保存在浏览器的明文 JSON |

## Public Interface · 对外边界

| 抽象 | 说明 |
|---|---|
| `ChatLLM.stream` | 文本 / ToolCall / Reasoning 流 |
| `ChatMessage` | system/user/assistant/tool，带工具关联与缓存断点 |
| `TurnLLMs` | 对话与后台模型组合 |
| `OwnKeys.for_turn/for_call` | 解析本次服务、租约与免限额判断 |
| `ServiceClients` / `Swappable` | 部署客户端工厂与延迟关闭旧客户端 |

## Internal Flow · 内部流程

```text
browser localStorage (per user) -> request own_keys
  -> OwnKeys -> borrowed models/services -> turn/call
  -> background extraction/title holds -> release

live config -> test replacement -> swap client
    old Lease ---------------------> last release -> close
```

## Dependencies · 依赖方向

- 使用：[[管理与运行观测]]的实时配置与价格目录、网络代理。
- 被使用：[[账号与准入]]、[[对话引擎]]、[[实时通话]]、[[记忆与搭话]]。
- [[前端导航与会话状态]]在请求时重新读取当前用户的 own_keys。

## Configuration · 配置

| 项 | 规则 |
|---|---|
| `CHAT_LLM_PROTOCOL` | chat-completions / responses / anthropic |
| `CHAT_LLM_REASONING_EFFORT` / `CHAT_LLM_CALL_REASONING_EFFORT` | 文字与通话分别选择 |
| `BACKGROUND_LLM_*` | 可单配；未分离时连接跟随对话模型，生成参数独立 |
| `EIDOLON_EXEMPTING_LLM/TTS/STT` | 通话需全部满足所选项才免限额；文字仅看自带 LLM |
| `EIDOLON_PROXY_URL/SERVICES` | 显式服务代理，不等同通用环境代理 |

## Testing · 如何验证

在 `backend/`：`uv run pytest tests/test_llm_protocols.py tests/test_own_keys.py tests/test_own_llm.py tests/test_own_keys_in_logs.py tests/test_exemption.py`；在 `frontend/`：`npm test -- src/lib/localOwnKeys.test.ts`。协议通过不证明真实模型会稳定遵守双语格式或工具指令。

> [!warning] 边界与常见误读
> 浏览器 localStorage 是明文，按用户 ID 隔离不代表加密。服务端会在回合、通话及其后台提炼/标题任务期间暂持密钥，但不持久化用户密钥。公网自带服务每次连接查地址；代理只允许已知提供商对应的主机。Reasoning 的回送受协议控制，不等于存入用户对话。
