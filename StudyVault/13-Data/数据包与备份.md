# 数据包与备份

重要度：★★★。阅读基线见 [[源码地图]]，先尝试 [[数据包与备份练习]] 再展开答案。

## Purpose · 职责

用户数据包只服务本人跨部署迁移，整库备份服务部署灾难恢复。两者都依赖格式和一致性检查，但权限、范围、加密方式及恢复操作完全不同。

## Key Files · 关键源码

| 源文件（项目根目录相对路径） | 职责 |
|---|---|
| `backend/src/eidolon/data_package.py` | 带版本 ZIP，离库校验后一次事务导入 |
| `backend/src/eidolon/data_package_api.py` | 本人导出/导入、流式请求与拒绝码 |
| `docs/data-package-format.md` | 跨部署数据包格式说明 |
| `backend/src/eidolon/backup.py` | 整库快照、压缩、age 公钥加密和保留期 |
| `backend/src/eidolon/restore.py` | 库完整性与替换检查 |
| `deploy/db-backup.sh` | 生产备份包装与退出码 |
| `deploy/db-restore.sh` | 先检查、备份、停后端、替换和重启 |
| `docs/adr/0025-data-packages-leave-affinity-and-gifts-behind.md` | 用户能带走什么 |

## Public Interface · 对外边界

| 边界 | 数据包 | 整库备份 |
|---|---|---|
| 发起者 | 用户本人 | 部署者或管理员功能 |
| 内容 | 所选对话/照片、记忆、制作人档案 | SQLite 全库 |
| 玩法状态 | 不导出当前好感、背包、次数、重置卡、任务成就进度 | 随库保留 |
| 落点 | 用户下载 ZIP | age 加密后私有 S3 |
| 恢复 | 合并本人数据，单次事务 | 停后端替换数据库 |

## Internal Flow · 内部流程

```text
export -> manifest.json (first, uncompressed) -> photos -> data.json
import -> unzip + validate off DB -> Database.write(one transaction)

backup -> independent snapshot -> integrity -> gzip -> age -> private S3
restore -> check -> backup current -> stop backend -> replace -> start
```

## Configuration · 配置

| 变量或约束 | 含义 |
|---|---|
| `EIDOLON_BACKUP_S3_*` | 私有备份桶，区别于公开立绘桶 |
| `EIDOLON_BACKUP_AGE_RECIPIENT` | 加密公钥；解密材料另行保管 |
| `EIDOLON_BACKUP_KEEP_DAYS` | 默认 30 天，最新一份始终保留 |
| ZIP FORMAT | 新版读旧版；旧版拒绝未知新版 |
| manifest/data 内容 | 范围和版本由格式文档及代码校验，不验事实真假 |

## Testing · 如何验证

在 `backend/`：`uv run pytest tests/test_data_package.py tests/test_data_package_photos.py tests/test_data_package_conversations.py tests/test_backup.py tests/test_restore.py`。覆盖坏 ZIP、新格式、缺角色、重复导入和整体回滚；恢复演练只用专用副本，本次没有操作实际数据。

> [!warning] 边界与常见误读
> 已导入消息上的好感变化标签只是历史，不修改当前好感数值。没有的角色其对话跳过，其来源记忆可保留；被用户下载的数据包不会随服务器删号自动消失。选择导入 profile 且包内有档案时，若与现档案不同，会用包内档案整体替换；对话合并不代表所有类别都只追加。
