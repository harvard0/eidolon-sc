# 学习地图

Eidolon-SC 新开发者的中文学习入口。项目面向单一作品的多角色实时对话：语音和文字共享引擎，日语回答配中文字幕，角色能检索剧情并保留用户记忆。

> [!important] 如何使用
> 从 [[开始学习]] 了解打开方式和本地运行条件；先读架构，再按模块查实际代码，最后做折叠答案练习。来源基线在 [[源码地图]]，本次验证范围在 [[质量自检]]。不需要先调用真实模型才能开始阅读。

## Architecture Overview · 架构概览

- [[系统架构]]：单进程模块化后端、前端、外部服务与数据边界。
- [[请求流程]]：文字 SSE、语音 WebRTC 从身份到提交与结算。
- [[数据流与一致性]]：持久数据、暂态、后台任务、取消与事务。
