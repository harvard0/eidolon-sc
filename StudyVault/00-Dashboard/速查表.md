## 配置按功能补齐 → [[模型协议与自带密钥]]

| 想开启的能力 | 关键输入 |
|---|---|
| 文字 | CHAT_LLM_BASE_URL/API_KEY/MODEL；本地开发登录 |
| 语音 | Fish + Soniox 或百炼；ICE/TURN 网络 |
| 检索、新记忆 | judge + embedding + rerank 三者 |
| 独立后台模型 | BACKGROUND_LLM_*，否则连接跟随对话模型 |
| 照片 | judge、生图服务、角色 photo_tag/appearance；另有小时限额 |
| 立绘 | 角色 idol_id/default_outfit、素材域和公开桶；前端 CSP 同域配置 |
| 好感/礼物 | 判断模型及 EIDOLON_AFFINITY_AND_GIFTS 开关 |
| 备份 | 独立 BACKUP_S3_* 与 age 公钥，保留期 |

环境模板是字段说明，不等于当前线上配置；[[管理与运行观测]]的 LiveConfig 可能覆盖它。完整入门命令见 [[开始学习]]。

## 数据不能混用 → [[数据流与一致性]]

用户数据包带对话/照片/记忆/档案，玩法当前状态不随行；整库备份是另一条恢复链路。公开立绘与私有照片使用不同权限模型。文字 SSE 增量、已提交消息、后台提炼结果和服务费用记录也分别判断。
