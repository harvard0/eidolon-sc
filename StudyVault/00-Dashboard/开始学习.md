# 开始学习

## 先用源码学习

把当前 `StudyVault/` 文件夹作为 Obsidian 仓库打开，从 [[学习地图]] 进入。无需启服务即可完成 trace、debug 与设计题；本库不依赖 Obsidian 插件，也没有写入 .obsidian 配置。

源码位置统一是**相对项目根目录**，不是相对笔记所在目录。代码仍留在 StudyVault 的同级项目中；wiki-link 只连接学习库里的笔记。阅读定位从 [[源码地图]] 开始。

## 本地前提

- Python 3.11+ 与 uv；Node 建议与 CI 一致使用 22，并安装 npm。
- 本地服务端口 :8000 和前端 :3000 可用。
- 启真实文字服务需能流式输出并支持工具调用的模型；只读学习无需凭证。
- PowerShell 与 Git Bash 的环境变量语法不同，下列启动命令按 PowerShell 写。

## 1. 根目录准备配置

```powershell
# 以下从项目根目录运行；已有配置时保持原文件
if (-not (Test-Path -LiteralPath '.env')) {
    Copy-Item -LiteralPath '.env.example' -Destination '.env'
}
```

在编辑器中填写 `CHAT_LLM_BASE_URL`、`CHAT_LLM_API_KEY`、`CHAT_LLM_MODEL`。只在本地启用 `EIDOLON_DEV_LOGIN=1`。密钥不写入本库或提交；语音、检索、图片稍后按 [[速查表]] 补齐。

## 2. 一个终端启动后端

```powershell
Set-Location backend
uv sync --locked
uv run --env-file=../.env eidolon serve
```

服务默认 :8000；角色默认路径相对 backend，见 [[运行时装配与数据库]]。启动可能检查真实模型能力并产生提供商请求，本次生成文档没有执行它。

## 3. 另一个终端启动构建版前端

```powershell
# 在项目根目录打开的另一个终端
Set-Location frontend
npm ci
npm run build
$env:BACKEND_URL = 'http://localhost:8000'
# 若需要立绘，把 EIDOLON_STAND_ASSETS_URL 设置为与后端相同的资源域
npm run start
```

打开浏览器的 `http://localhost:3000`，点登录 → 开发登录，使用专门的学习用户，同意隐私政策/条款并声明年龄符合要求，再点角色发一条文字消息。不要为了学习覆盖现有用户数据。

## 4. 独立验证

在 backend 终端执行：

```powershell
uv run ruff check
uv run pyright
uv run pytest
```

在 frontend 终端执行：

```powershell
npm run typecheck
npm test
```

纪律检查在 frontend 的 Git Bash/WSL 终端执行 `sh scripts/check-discipline.sh`。不要为缺少 shell 编造 npm lint 命令；package.json 没有这个脚本。前端构建、全量后端测试、Playwright 等重活串行。

## 5. 浏览器验收与停止

按 `docs/agents/local-acceptance.md` 使用构建版、专用开发用户、假麦克风。拦 offer 测拨号失败，连接后结束事件需要假 WebRTC 对端。界面、通话、模型语义各留独立证据，见 [[部署与开发验证]]。

先在启动终端 Ctrl+C。若端口仍被占用，PowerShell 用 `Get-NetTCPConnection -LocalPort 3000 -State Listen` 确认 OwningProcess，核对命令行归属后再停该进程，:8000 同理；不能按端口号猜测就杀进程。
