# 好感度玩法与日历

重要度：★★★。阅读基线见 [[源码地图]]，先尝试 [[好感度玩法与日历练习]] 再展开答案。

## Purpose · 职责

好感度是每位用户与每个角色之间独立且跨对话保留的数值，用户只见档位。Happenings 把玩法行为与任务奖励放进同一事务；日历把角色生日、制作人生日和日本节假日呈现并按各自时区进入提示词。

## Key Files · 关键源码

| 源文件（项目根目录相对路径） | 职责 |
|---|---|
| `backend/src/eidolon/affinity.py` | 好感度公式、档位、恢复、冷却及礼物常量 |
| `backend/src/eidolon/affinity_judge.py` | 本轮情绪与越界判断 |
| `backend/src/eidolon/gifts.py` | 背包、次数、重置卡及奖励去重 |
| `backend/src/eidolon/happenings.py` | 回合、通话、送礼、抽奖与任务奖励的共同事务 |
| `backend/src/eidolon/achievements.py` | 成就定义和进度 |
| `backend/src/eidolon/calendar_api.py` | 一年日本节假日列表 |
| `backend/src/eidolon/today.py` | 东京生日/节假日写入本轮提示 |
| `frontend/src/lib/calendar.ts` | 日历合并模型 |
| `frontend/src/components/play/CalendarSubpage.tsx` | 日历页面 |

## Public Interface · 对外边界

| 边界 | 作用 |
|---|---|
| Affinities | 惰性恢复、变化、冷却、档位 |
| Happenings | 回合/送礼/通话/抽奖与奖励联动 |
| `/api/gifts`、`/api/gifts/draws` | 状态与抽奖 |
| `/api/characters/{character_id}/gifts` | 送礼并产生对话事件 |
| `/api/calendar/holidays?year=YYYY` | 已登录用户查询，不合法年份返回空列表 |
| `today_lines` / producer.now_prompt | 东京角色节日、制作人本地生日分别处理 |

## Internal Flow · 内部流程

```text
judged turn -> engine._record -> affinity + message + Happenings -> reward
gift/draw -> Happenings -> backpack / affinity / daily task / achievement
reading time -> lazy recovery + daily draw grant

character birthdays + profile birthday + Japanese holidays -> calendar
Tokyo date / producer local date -> per-turn prompt
```

## Configuration · 配置

| 配置 | 规则 |
|---|---|
| `EIDOLON_AFFINITY_AND_GIFTS` | 开关；同时需要判断模型 |
| 好感度数值与奖励规则 | 统一在 affinity.py 等源码，不由环境或后台任意改数 |
| 每日任务/发抽奖次数 | 按北京时间，不随浏览器时区 |
| 角色生日、日本节假日 | 按东京当天；制作人生日按档案/有效用户时区 |
| 生日字段 | 只有月日；非闰年 2 月 29 日按 2 月 28 日 |

## Testing · 如何验证

在 `backend/`：`uv run pytest tests/test_affinity.py tests/test_gift_giving.py tests/test_daily_tasks.py tests/test_all_or_nothing.py tests/test_calendar.py`；在 `frontend/`：`npm test -- src/lib/calendar.test.ts src/lib/calendarFilter.test.ts`。日期用 fake clock 固定，覆盖东京/北京/制作人时区跨日。

> [!warning] 边界与常见误读
> 恢复和每日次数在读取时计算，不是每天定时写所有用户。失败回合不变好感；数据包导入不触发任务。关闭玩法保留旧数据，关闭期间不补发每日次数。日历接口只返回节假日，生日来自角色列表和档案。
