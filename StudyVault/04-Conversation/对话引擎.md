# 对话引擎

重要度：★★★。阅读基线见 [[源码地图]]，先尝试 [[对话引擎练习]] 再展开答案。

## Purpose · 职责

同一个引擎接收文字输入并流式输出日语与中文字幕，不负责麦克风或音频传输。成功回合将双方消息及关联好感度、照片和任务进度一起提交；中途可见的增量不等于已经持久化。

## Key Files · 关键源码

| 源文件（项目根目录相对路径） | 职责 |
|---|---|
| `backend/src/eidolon/engine.py` | ConversationEngine.turn/_reply/_prompt/_record |
| `backend/src/eidolon/reply_format.py` | 日中标签解析、分段完成与语音增量 |

| `backend/src/eidolon/titles.py` | 第三回合后后台起标题 |
| `backend/src/eidolon/app.py` | 文字 SSE 路由与事件筛选 |

## Public Interface · 对外边界

| 入口或对象 | 作用 |
|---|---|
| `ConversationEngine.turn` | text、TurnLLMs、可选 stop / InCall，产出 TurnEvent |
| `ReplyParser` | `<ja>…</ja><zh>…</zh>` → 增量与完整段 |
| `_prompt` | 稳定角色上下文 → 档案 → 历史 → 本轮动态 system → 用户 |
| `_keep/_record` | 同一事务记录业务，提交后通知与后台派生 |
| `recall-story` | 可用时提供给模型，最多补一次工具往返 |

## Internal Flow · 内部流程

```text
text -> validate -> read snapshot -> memory.begin + retrieval
     -> prompt -> LLM stream -> ReplyParser -> delta
     -> complete segments -> _keep -> Database.write(_record)
     -> memories.write_down + titles.after_turn -> done
     -> HTTP SSE or call data channel
```

## Configuration · 配置

| 变量或常量 | 含义 |
|---|---|
| `EIDOLON_HISTORY_TURNS` | 保留近期回合；chat_history 按阶段裁剪以保留前缀 |
| `MAX_INPUT_LENGTH` | 当前源码为 2000 字符 |
| `CHAT_LLM_*` | 对话模型与思考配置 |
| `BACKGROUND_LLM_*` | 提炼记忆、标题；连接可跟随对话模型 |

## Testing · 如何验证

在 `backend/`：`uv run pytest tests/test_text_turn.py tests/test_dynamic_context.py tests/test_turns.py tests/test_all_or_nothing.py`。`test_text_turn.py` 从外部 API 读取 SSE；断开连接用真实 ASGI disconnect 事件模拟，httpx 的 ASGITransport 提前关流并不足够。

> [!warning] 边界与常见误读
> 普通失败或空完整回复不留回合；通话主动打断是特殊停止路径，会保存当时已完整的段。SegmentComplete/SpeechDelta/TurnJudged 留在服务端，不直接发进文字 SSE。每轮检索和时间只进本轮动态 system；对话标题不进提示词。
