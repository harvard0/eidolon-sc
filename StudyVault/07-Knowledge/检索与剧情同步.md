# 检索与剧情同步

重要度：★★★。阅读基线见 [[源码地图]]，先尝试 [[检索与剧情同步练习]] 再展开答案。

## Purpose · 职责

这里决定本轮应查什么，而不是让每句闲聊都携带全部资料。剧情按角色出场范围过滤，角色事实和作品事实按语义检索；同步/导入与在线回合分开，原始剧情不随仓库分发。

## Key Files · 关键源码

| 源文件（项目根目录相对路径） | 职责 |
|---|---|
| `backend/src/eidolon/retrieval.py` | judge 分流、投机候选检索、重排与 recall-story |
| `backend/src/eidolon/corpus.py` | 剧情片段与整集、角色出场过滤、向量加载 |
| `backend/src/eidolon/facts.py` | 角色资料的标题切分 |
| `backend/src/eidolon/work_facts.py` | 作品歌曲与演出资料 |
| `backend/src/eidolon/story_sync.py` | 翻译 CSV 与日语镜像补齐 |
| `backend/src/eidolon/world_sync.py` | 作品设定同步 |
| `backend/src/eidolon/reembed.py` | 切换向量模型后的重建 |
| `backend/src/eidolon/assembly.py` | judge/embedder/reranker 三者齐备才装配检索 |

## Public Interface · 对外边界

| 入口 | 结果 |
|---|---|
| `Retrieval.retrieve` | Retrieved：资料、记忆、判断与查询向量 |
| need = nothing / memories / references / recall | 无需资料 / 记忆 / 混合资料 / 整集回忆 |
| `recall_story(character, query)` | 工具主动查询，限制该角色出场的剧情 |
| `eidolon story sync` / `world sync` | CLI 维护剧情与作品设定 |
| `eidolon reembed` | 模型或维度变化后重建各来源向量 |

## Internal Flow · 内部流程

```text
latest reply + input -> one query vector -> source candidates
                     \-> judge (in parallel)
                           |
 nothing -> cancel         +-> memories -> memory rerank
 references -> mixed-source rerank + memory rerank
 recall -> whole episodes + live/release context
                     -> per-turn prompt -> engine
```

## Dependencies · 依赖方向

- 使用：向量服务、SiliconFlow 重排、判断模型、SQLite 与世界设定。
- 与 [[记忆与搭话]]共用本轮查询向量；给 [[对话引擎]]返回上下文。
- [[角色与多媒体]]的角色资料决定出场名与事实来源。

## Configuration · 配置

| 变量 | 用途 |
|---|---|
| `EMBEDDING_PROVIDER/MODEL/DIMENSIONS` | SiliconFlow 或 Gemini 及向量身份 |
| `SILICONFLOW_API_KEY` | 默认向量化与重排 |
| `GEMINI_API_KEY` / `GEMINI_BILLING_ENABLED` | 可选 Gemini 路径及其部署声明 |
| `JUDGE_PROVIDER` 与所选服务凭证 | Jev / Cloudflare / 百炼判断模型 |
| `RERANK_MODEL/MIN_RELEVANCE/MEMORY_MIN_RELEVANCE` | 模型相关阈值，未知模型需校准 |

## Testing · 如何验证

在 `backend/`：`uv run pytest tests/test_retrieval.py tests/test_recall_story.py tests/test_story_sync.py tests/test_world_retrieval.py tests/test_reembed.py`。真实质量评测入口是 `eidolon eval rerank`、`eidolon eval judge`、`eidolon eval memory`，会访问已配置服务；本次没有运行这些评测。

> [!warning] 边界与常见误读
> 判断失败默认检索 references；embedding 失败继续聊天但无资料/记忆；重排失败资料可回退最近向量候选，记忆不作同样回退。虽然闲聊最终不用资料，judge 与向量候选会并行启动，所以不能写成闲聊绝无 embedding 请求。
