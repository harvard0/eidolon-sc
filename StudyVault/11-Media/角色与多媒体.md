# 角色与多媒体

重要度：★★★。阅读基线见 [[源码地图]]，先尝试 [[角色与多媒体练习]] 再展开答案。

## Purpose · 职责

角色配置连接人设、事实、音色、生日与视觉资源。立绘和预生成招呼音频走对象存储；角色发送的私有照片走数据库与用户权限接口，这两种素材有不同生命周期。

## Key Files · 关键源码

| 源文件（项目根目录相对路径） | 职责 |
|---|---|
| `characters/characters.toml` | 角色 ID、人设路径、生日、音色、照片和衣装配置 |
| `backend/src/eidolon/characters.py` | TOML 加载与引用校验 |
| `backend/src/eidolon/photos.py` | 照片资格、排队、限额及记录协调 |
| `backend/src/eidolon/photo_prompt.py` | 生图提示组合和内容标签边界 |
| `backend/src/eidolon/photos_api.py` | 本人读取照片状态和图像 |
| `backend/src/eidolon/stand_upload.py` | 立绘/衣装目录上传到对象存储 |
| `backend/src/eidolon/readings.py` | 专有名词读音 |
| `frontend/src/components/conversations/stand/StandEngine.ts` | Spine 渲染、轨道、口型和资源生命周期 |
| `docs/adr/0024-photos-stored-in-the-database.md` | 照片进 SQLite 的决策 |

## Public Interface · 对外边界

| 入口 | 说明 |
|---|---|
| `load_characters` | 加载并校验角色及相对配置引用 |
| Photos.begin / recorded / dropped | 生成可先开始，但必须和成功回复建立关联 |
| `/api/photos/{photo_id}` / `image` | pending/ready/failed 与私有图像 |
| `eidolon stand fetch/outfits/upload` | 素材、目录、上传三个步骤 |
| `eidolon greeting upload` | 按读音和台词预合成上传 |
| StandEngine | data.json / data.atlas / data.png 的播放与释放 |

## Internal Flow · 内部流程

```text
characters.toml -> sheet + facts + voice + birthday + photo tags
  -> API characters -> frontend herVars / avatar / outfit

judge asks-photo -> LLM photo tag closes -> queue generation
  -> reply transaction associates id -> picture stored -> ready/failed

stand fetch -> outfit list -> S3 -> browser Spine
complete segment -> emotion + speaking -> stand direction / mouth
```

## Dependencies · 依赖方向

- 使用：[[模型协议与自带密钥]]的合成/生图服务、[[运行时装配与数据库]]。
- 被使用：[[对话引擎]]、[[实时通话]]、[[检索与剧情同步]]、[[前端导航与会话状态]]。
- [[数据包与备份]]可以携带本人已发送的照片，不能携带私有原作素材。

## Configuration · 配置

| 配置 | 说明 |
|---|---|
| photo_tag + photo_appearance | 两者齐备才具备发照片的角色配置 |
| `NOVELAI_*` | 生图格式、连接、模型、并发和风格 |
| `EIDOLON_PHOTOS_PER_HOUR` | 部署照片限额；用户自带生图不计 |
| `EIDOLON_STAND_ASSETS_URL` 与 `EIDOLON_STAND_S3_*` | 公开资源域与维护上传凭证 |
| `characters/readings.toml` | 合成读音，配合 voice_id |

## Testing · 如何验证

在 `backend/`：`uv run pytest tests/test_characters.py tests/test_photos.py tests/test_photo_records.py tests/test_photo_failures.py tests/test_stand_upload.py tests/test_readings.py`；在 `frontend/`：`npm test -- src/lib/standAnimations.test.ts src/lib/standFrames.test.ts`。Spine 视觉、口型和听感需浏览器及人工验证。

> [!warning] 边界与常见误读
> 照片 pending 可早于回合提交；生成成功不代表回复已保存。页面关闭不会自动取消已花费的生图。自带生图失败不换部署密钥。日语记录中的 delivery cues 展示前会去掉；它们不是中文字幕内容。原作剧情、音色和立绘不属于代码许可证覆盖的自产素材。
