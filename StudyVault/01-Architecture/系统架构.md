# 系统架构

项目是模块化的单进程后端加独立 Next.js 前端，当前没有消息队列或跨进程通话服务。领域术语以根目录 `GLOSSARY.md` 为准，设计原因查 `docs/adr/`，本库只为阅读现有实现导航。

```text
 Browser: Next.js / React / Base UI / Tailwind v4
    | HTTP + SSE (same origin)         | WebRTC audio + data
    v                                  v
 Next API proxy -----------------> FastAPI + Pipecat Calls
                                       |          |
                                Admissions    CallTurns
                                       +----------+
                                            |
                                    ConversationEngine
                              +-------------+-------------+
                              |             |             |
                         Retrieval       Memories      LLM adapters
                              |             |             |
                         corpus/facts  background LLM  provider APIs
                              +-------------+
                                            |
                              Database: writer + read pool
                                            |
                                  SQLite: one deployment

 public object storage -> stands / greetings -> browser
 private photos -> SQLite -> owner-only API -> browser
```

## 技术栈与职责

| 层 | 技术与边界 | 深入阅读 |
|---|---|---|
| HTTP 与身份 | FastAPI、Pydantic、Cookie OAuth | [[账号与准入]] |
| 流式角色回复 | 自有引擎 + 三类 LLM 协议适配 | [[对话引擎]]、[[模型协议与自带密钥]] |
| 音频 | Pipecat + SmallWebRTC、Soniox/百炼、Fish | [[实时通话]] |
| 检索 | Judge + Embedding + Reranker，原文 SQLite | [[检索与剧情同步]] |
| 用户连续性 | 共享记忆、后台提炼、搭话 | [[记忆与搭话]] |
| 数据一致性 | SQLite WAL、专用写线程、读池 | [[运行时装配与数据库]] |
| 应用界面 | Next 16、React 19、Base UI、Tailwind 4 | [[前端导航与会话状态]] |
| 业务扩展 | 好感度、礼物、任务、成就、日历、照片 | [[好感度玩法与日历]]、[[角色与多媒体]] |
| 运维 | 实时配置、调用记录、状态、统计、备份 | [[管理与运行观测]]、[[数据包与备份]] |

版本来自依赖清单约束；安装解析以 `backend/uv.lock` 与 `frontend/package-lock.json` 为准，不把清单下限当成当前已安装版本。

## 模块之间如何连接

1. [[运行时装配与数据库]]的 build 是唯一装配根：配置决定服务工厂、外部依赖及后台循环。
2. [[账号与准入]]先固定身份、服务选择与限额，领域引擎不再到处判断用户带了谁的 key。
3. [[对话引擎]]不懂音频；[[实时通话]]把识别文本和合成包装在它外面。
4. 流式增量与数据库提交分离，见 [[数据流与一致性]]。
5. 前端导航外壳拥有正在通话的状态，组件依赖可订阅模型，见 [[前端导航与会话状态]]。

> [!important] 外部依赖分层
> 最小文字聊天只需流式工具调用模型。检索/新记忆需要 judge、embedding、reranker 齐备；语音、照片、立绘分别需要自己的服务或素材。仓库不分发完整剧情、角色音色与立绘，缺少它们不代表代码模块不存在。
